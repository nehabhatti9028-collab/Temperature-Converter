# 🌡️ Temperature Converter Website

A modern and responsive Temperature Converter website built using HTML, CSS, and JavaScript. It allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin with instant results.

## ✨ Features

- Convert Celsius, Fahrenheit, and Kelvin.
- Display all three temperature units together.
- Input validation for invalid values.
- Absolute zero validation.
- Responsive and user-friendly design.
- Interactive conversion button.
- Clean dark teal and mint color theme.

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Conversion logic and validation

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Enter a temperature value.
5. Select the input unit.
6. Click **Convert Temperature** to view the results.

## 🧮 Conversion Formulas

- Fahrenheit = (Celsius × 9/5) + 32
- Kelvin = Celsius + 273.15
- Celsius = (Fahrenheit − 32) × 5/9
